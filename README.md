# Cash Offer Acres

Static marketing website for Cash Offer Acres.

## Structure

- `index.html` - main landing page
- `privacyPolicy.html` and `termsOfService.html` - legal pages
- `css/` - site styles
- `scripts/` - landing animation, form embed, and page interactions
- `images/` and `videos/` - static media assets

The contact form is embedded from Stride CRM, so this site does not need a backend for the current static-hosting setup.
